# trabajoN3_Paradigmas
El desarrollo de este sistema permitió aplicar los principios fundamentales de la Programación Orientada a Objetos basada en prototipos. La solución favorece una organización de los datos y comportamientos relacionados con la gestión de tareas, promoviendo la modularidad y la reutilización del código. 
Asimismo, la utilización de interfaces y prototipos permitió resolver el problema de manera eficiente, manteniendo una estructura clara. Las características de herencia y polimorfismo no fueron implementadas que no requería la definición de objetos y comportamientos alternativos para múltiples tipos de entidades.
En consecuencia, la solución desarrollada resulta cumple con los requisitos, aplicando los conceptos de POO.
